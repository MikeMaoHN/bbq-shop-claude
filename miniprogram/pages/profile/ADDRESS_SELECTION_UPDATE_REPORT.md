- [x] 自动返回订单确认页
- [x] 订单页自动刷新地址信息

**实现代码**: `profile.js` 第 232-242 行
```javascript
if (this.data.selectAddressMode) {
  const pages = getCurrentPages();
  const prevPage = pages[pages.length - 2];
  if (prevPage && prevPage.setData) {
    if (typeof prevPage.loadAddress === 'function') {
      prevPage.loadAddress();
    }
  }
  wx.navigateBack();
}
```
