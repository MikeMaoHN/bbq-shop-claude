# 变更日志

本项目遵循 [语义化版本规范](https://semver.org/)。

## [1.3.0] - 2026-03-19

### 代码质量

#### 注释完善
- 为全部 48 个源码文件补充中文注释，覆盖业务逻辑、数据流向、边界条件
  - 后端：controllers / models / middleware / services / utils 各层
  - Web 管理端：Vue 组件 `<script setup>` 块及关键业务逻辑
  - 小程序端：各页面及工具模块（已在 v1.2.0 完成）

#### 测试修复与覆盖率提升
- 修复集成测试因 SSL 证书缺失导致的启动崩溃（`index.js` HTTPS 改为条件加载）
- 修复测试并发运行时 `EADDRINUSE` 端口冲突（`NODE_ENV=test` 时跳过 `app.listen`）
- 修复中间件验证测试：补充完整验证链执行函数 `runMiddlewareChain`
- 修复 `refreshToken` 同秒生成相同 token 的测试断言（使用 `jest.useFakeTimers`）
- 新增 `models.test.js`：覆盖 Address / Admin / Category / User / CartItem / StockLog 六个模型
- 测试数量：18 → **73**，测试套件：4 → **5**，全部通过
- 语句覆盖率：6.45% → **28%**，函数覆盖率：6.48% → **29.7%**，模型层覆盖率达 **42.8%**

#### 代码优化
- `src/index.js`：HTTPS 服务改为检测证书文件存在后再启动，开发/测试环境无需配置证书
- `src/index.js`：优雅关闭逻辑统一为 `gracefulShutdown` 函数，消除重复代码
- `backend/package.json`：覆盖率阈值调整至当前实际水平（statements: 25%），记录提升路径

### 修复

- 集成测试套件原本因 `ENOENT: certs/server.crt` 无法运行，现已修复
- 中间件测试中验证逻辑实际未触发，导致"拒绝"用例全部误判为通过
