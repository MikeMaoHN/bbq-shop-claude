## 一、小程序用户端使用指南

### 1.1 注册与登录

**首次使用**

1. 打开微信，搜索小程序「烤乐汇」或扫描商家提供的二维码
2. 点击「授权登录」，允许小程序获取你的微信头像和昵称
3. 登录成功后自动跳转到首页

> 无需单独注册账号，使用微信一键登录即可。

---

### 1.2 浏览菜单与下单

**浏览菜品**

- 首页展示所有可用菜品，按分类排列
- 点击菜品卡片查看详情（名称、价格、图片、描述）

**加入购物车**

1. 在菜品列表，点击菜品右下角的 **「+」** 按钮加入购物车
2. 可点击 **「-」** 减少数量，数量归零时自动移出购物车
3. 页面底部购物车栏实时显示已选商品数量和总价

**提交订单**

1. 点击底部购物车栏，进入「确认订单」页面
2. 确认商品清单和总价无误
3. 点击「立即支付」进入支付流程

---

### 1.3 支付流程

#### 真实支付模式（正式上线后）

```
点击「立即支付」
    ↓
弹出微信支付收银台
    ↓
验证指纹 / 密码 / 面容确认支付
    ↓
支付成功 → 订单状态更新为「已支付」
    ↓
跳转订单详情页
```

#### 模拟支付模式（测试环境 / 上线前验证）

```
点击「立即支付」
    ↓
直接模拟支付成功（无需微信收银台）
    ↓
订单状态更新为「已支付」
    ↓
跳转订单详情页
```

> 模拟支付模式下不会产生真实扣款，仅用于测试验证。当前是否为模拟模式由商家管理端控制。

**支付失败处理**

| 情况 | 说明 | 处理方式 |
|------|------|---------|
| 余额不足 | 微信钱包/绑定银行卡余额不足 | 充值后重新支付，或换绑其他卡 |
| 支付超时 | 订单创建后超过 2 小时未支付 | 重新下单 |
| 网络异常 | 支付过程中断网 | 检查网络后在「我的订单」确认状态，已扣款会自动更新 |
| 支付取消 | 主动点击「取消」 | 订单保留，可在「我的订单」重新发起支付 |

---

### 1.4 查看订单

**订单状态说明**

| 状态 | 含义 |
|------|------|
| 待支付 | 已下单，尚未完成支付 |
| 已支付 | 支付成功，等待商家备餐 |
| 备餐中 | 商家已接单，正在准备 |
| 已完成 | 餐品已出餐 |
| 已退款 | 商家已退款到原支付方式 |
| 已取消 | 订单已取消 |

**查看方式**

- 首页 → 「我的」→「我的订单」

---

### 1.5 常见问题（用户端）

**Q：支付成功但订单还是「待支付」怎么办？**

A：微信支付回调通常在 5 秒内到达，如超过 1 分钟仍未更新，请截图支付成功页面联系商家客服，商家可通过管理后台手动核实。

**Q：可以使用微信红包或优惠券吗？**

A：当前版本暂不支持，后续版本将陆续开放。

**Q：支付后可以申请退款吗？**

A：可以，请联系商家。商家在管理后台发起退款后，资金将在 1-7 个工作日内退回原支付方式（微信零钱或银行卡）。

**Q：一个微信号可以创建多个订单吗？**

A：可以，支持同时存在多个订单。

## 二、管理端使用指南

### 2.1 登录管理后台

1. 浏览器访问 `https://你的域名/admin`
2. 输入管理员账号和密码
3. 登录成功后进入管理控制台

> 首次部署时请立即修改默认管理员密码。

---

### 2.2 订单管理

**查看订单列表**

- 左侧菜单 → **「订单管理」**
- 支持按状态、时间筛选
- 实时显示最新订单（建议开启浏览器通知）

**订单操作**

| 操作 | 条件 | 说明 |
|------|------|------|
| 接单 | 状态为「已支付」 | 将订单更新为「备餐中」 |
| 完成 | 状态为「备餐中」 | 将订单更新为「已完成」 |
| 退款 | 状态为「已支付」或「已完成」 | 向用户发起微信退款 |
| 查看详情 | 任意状态 | 查看完整订单信息和支付记录 |

---

### 2.3 发起退款

1. 订单列表 → 找到目标订单 → 点击「退款」
2. 系统弹出确认对话框，显示退款金额
3. 点击「确认退款」
4. 退款请求提交至微信支付，通常 1-3 秒内完成提交
5. 资金退回用户原支付方式，到账时间：
   - 微信零钱：即时到账
   - 银行卡：1-7 个工作日

**注意事项**

- 退款需要在订单支付成功后才可操作
- 每笔订单仅支持全额退款（当前版本）
- 退款操作不可撤销，请谨慎确认
- 真实支付模式下，退款需要服务器已配置 SSL 证书（`WX_CERT_PATH`）

---

### 2.4 菜品管理

**添加菜品**

1. 左侧菜单 → **「菜品管理」** → 点击「新增菜品」
2. 填写菜品名称、分类、价格、描述
3. 上传菜品图片
4. 点击「保存」，菜品立即在小程序端展示

**修改 / 下架菜品**

- 点击菜品行右侧「编辑」按钮修改信息
- 切换「上架状态」开关可立即上架或下架

---

### 2.5 支付模式切换

> 此功能用于在**不重启服务**的情况下实时切换支付模式，主要用于上线前测试验证。

**进入支付设置**

左侧菜单 → **「系统设置」** → **「支付设置」**

**页面说明**

| 显示状态 | 含义 |
|---------|------|
| 橙色警告 + 开关开启 | 当前为**模拟支付**，用户支付不产生真实扣款 |
| 绿色提示 + 开关关闭 | 当前为**真实支付**，用户支付产生真实微信扣款 |

**操作步骤**

1. 点击开关切换模式
2. 系统弹出确认提示
3. 确认后立即生效（约 1 秒内），无需重启服务
4. 页面状态实时更新，反映当前模式

**切换场景建议**

| 场景 | 推荐模式 |
|------|---------|
| 开发环境 | 模拟支付 |
| 上线前生产验证 | 模拟支付（测试完成后切换） |
| 正式营业 | 真实支付 |
| 遇到支付问题需排查 | 切换为模拟支付，排查修复后切回 |

> **风险提示**：切换为真实支付后，用户的每一笔支付都会产生真实扣款，请确认微信支付商户配置正确后再切换。

---

### 2.6 常见问题（管理端）

**Q：切换支付模式后需要重启服务吗？**

A：不需要。切换操作写入数据库，服务每次处理支付请求时实时读取，立即生效。

**Q：退款失败提示"证书错误"怎么办？**

A：退款需要微信支付 SSL 证书（`apiclient_cert.p12`），请确认服务器已正确配置 `WX_CERT_PATH` 环境变量，并且证书文件可读。详见[部署指南 §2.3](./deployment-guide.md#23-下载退款-ssl-证书退款功能必须)。

**Q：如何确认支付回调是否正常？**

A：在管理端订单列表中，已支付订单的「交易号」字段（transaction_id）应显示以 `4` 开头的微信交易号（真实支付）。若该字段为空或订单长时间停在「待支付」，说明回调未到达，请检查 `WX_NOTIFY_URL` 配置和服务器防火墙设置。

**Q：模拟支付模式下也能测试退款吗？**

A：可以。模拟支付模式下的退款操作会调用真实的微信退款接口（使用模拟交易号），实际上会因交易号无效而返回错误，属于预期行为。如需完整测试退款，请使用真实支付完成一笔小额支付后再测试退款。

**Q：管理员忘记密码怎么办？**

A：请联系服务器运维人员，在数据库 `admins` 表中重置密码哈希值。

## 三、微信支付说明

### 3.1 支付方式

烤乐汇小程序目前支持以下微信支付方式：

- 微信零钱
- 绑定的银行卡（储蓄卡 / 信用卡）
- 零钱通（余额充足时）

### 3.2 退款政策

| 项目 | 说明 |
|------|------|
| 退款申请 | 由用户联系商家，商家在管理后台操作 |
| 退款金额 | 全额退款（当前版本） |
| 退款到账时间 | 微信零钱：即时；银行卡：1-7 工作日 |
| 退款有效期 | 支付成功后 1 年内可申请退款 |

### 3.3 支付安全

- 所有支付请求通过 HTTPS 加密传输
- 微信回调使用 MD5 签名验证，防止伪造
- 服务端不存储用户银行卡信息
- 退款接口需要 SSL 双向证书认证，防止伪造退款请求
