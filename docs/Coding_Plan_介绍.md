# 阿里云百炼 Coding Plan 介绍文档

## 一、什么是 Coding Plan？

Coding Plan 是阿里云百炼平台推出的 **AI 编程订阅服务**，以固定月费模式提供海量 API 调用额度，专为高频编码场景设计。

---

## 二、支持的大模型

| 模型 | 厂商 | 特点 |
|------|------|------|
| Qwen3.5 / Qwen3-Max | 通义千问 | 编程能力强，性价比高 |
| GLM-5 / GLM-4.7 | 智谱AI | 旗舰开源模型 |
| Kimi K2.5 | 月之暗面 | 智能体能力优秀 |
| MiniMax M2.5 | MiniMax | Agent 场景原生设计 |

用户订阅后可自由切换以上模型，根据不同任务选择最优模型。

| 套餐 | 请求额度 | 首月优惠 | 次月 | 第三个月起 |

## 四、支持的 AI 编程工具

Coding Plan 通过标准 API 接口，兼容多种主流 AI 编程助手：

- **Qwen Code**（阿里开源）
- **Claude Code**
- **Cline**
- **OpenClaw**

安装工具后，配置阿里云百炼 API 即可使用。
