# 系统设计文档

## 1. 系统概述

### 1.1 系统定位

bbq-shop 是一个烧烤食材售卖电商平台，包含：
- **小程序端**：C 端用户购物
- **Web 管理端**：B 端商家管理
- **后端 API**：统一服务提供

### 1.2 用户角色

| 角色 | 权限 |
|------|------|
| 普通用户 | 浏览商品、购物车、下单、支付 |
| 管理员 | 商品管理、订单管理、库存管理 |

         ┌──────────────────▼───────────────────┐

## 4. 核心流程

### 4.1 用户登录流程

```
┌─────┐      ┌─────┐      ┌─────┐      ┌─────┐
│用户 │      │小程序│      │后端 │      │微信 │
└──┬──┘      └──┬──┘      └──┬──┘      └──┬──┘
   │点击登录    │          │          │
   │─────────> │          │          │
   │          │wx.login() │          │
   │          │─────────> │          │
   │          │  code     │          │
   │          │─────────> │          │
   │          │          │POST /api/auth/wx-login
   │          │          │─────────> │
   │          │          │          │code2Session
   │          │          │          │─────────>
   │          │          │          │返回 openid
   │          │          │<─────────│
   │          │          │生成 Token
   │          │          │返回 Token+User
   │          │<─────────│          │
   │          │<─────────│          │
   │  登录成功 │          │          │
   │<─────────│          │          │
```

### 4.2 订单创建流程

```
1. 用户选择商品 → 加入购物车
2. 点击"去结算" → 订单确认页
3. 选择地址 → 提交订单
4. 后端验证：
   - 地址有效性
   - 商品库存
   - 商品状态
5. 开启事务：
   - 创建订单记录
   - 创建订单明细
   - 扣减商品库存
6. 提交事务 → 返回订单号
7. 跳转支付
```

### 4.3 支付流程 (MOCK 模式)

```
用户点击支付
    │
    ▼
POST /api/order/:id/pay
    │
    ▼
验证订单状态 (待付款)
    │
    ▼
开启事务：
  - 更新订单状态→待发货
  - 记录支付时间
    │
    ▼
提交事务
    │
    ▼
返回"支付成功"
    │
    ▼
小程序刷新订单列表
```

### 4.4 支付流程 (REAL 模式)

```
用户点击支付
    │
    ▼
POST /api/order/:id/pay
    │
    ▼
调用微信支付统一下单
    │
    ▼
返回支付参数 (prepay_id 等)
    │
    ▼
小程序调用 wx.requestPayment
    │
    ▼
用户输入密码/指纹验证
    │
    ▼
微信扣款成功
    │
    ▼
微信回调 /api/pay/notify
    │
    ▼
验证签名 → 更新订单状态
    │
    ▼
返回 SUCCESS 给微信
```

## 7. 性能优化

### 7.1 小程序端优化

| 优化项 | 方案 | 效果 |
|--------|------|------|
| 图片加载 | CDN 加速 + 懒加载 | 加载速度 +50% |
| 列表渲染 | wx:key + 分页 | 渲染性能 +30% |
| 请求合并 | Promise.all | 减少等待时间 |
| 数据缓存 | Storage 缓存 | 减少网络请求 |

### 7.2 后端优化

| 优化项 | 方案 | 效果 |
|--------|------|------|
| 数据库索引 | 常用查询字段 | 查询速度 +80% |
| 连接池 | Sequelize pool | 并发能力提升 |
| 静态资源 | Nginx 托管 | 减轻应用负载 |
| 集群部署 | PM2 cluster | 多核 CPU 利用 |
